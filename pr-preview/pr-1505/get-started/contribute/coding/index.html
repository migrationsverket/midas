🛠️ Sätt upp utvecklingsmiljön

Du behöver Node.js version 24 och git.

git clone https://github.com/migrationsverket/midas.git
cd midas
npm ci
npx playwright install chromium

Komponenttesterna körs i en riktig webbläsare, och playwright install hämtar den.

Vanliga kommandon​

Midas är ett monorepo som hanteras med Nx. Komponentbiblioteket, dokumentationswebben och verktygen är olika projekt i samma repo, och npx nx graph visar hur de hänger ihop.

npx nx serve storybook    # Storybook på http://localhost:4400
npx nx serve docs         # Dokumentationswebben på http://localhost:3000
npx nx serve playground   # En sandlåda för att prova komponenter, på http://localhost:4200
npx nx test components    # Komponenttesterna

Komponenterna ligger i packages/components och dokumentationswebben i apps/docs. Mer om testerna finns på sidan om tester.

🧪 Testa i en annan app​

Vill du testa din lokala version av Midas i en annan app, innan den är släppt, kan du publicera den till ett lokalt Verdaccio-registry:

npx nx run @midas-ds/source:release:local:dev

Installera det sedan i din app:

npm install @midas-ds/components@latest --registry=http://localhost:4873/

Skriptet ändrar package.json-filer med tillfälliga versioner (t.ex. 15.2.7-local.0). Committa inte de ändringarna! Återställ dem när du är klar:

git checkout -- packages/*/package.json

🐳 Starta allt med Docker​

Vill du ha flera tjänster igång på en gång kan du starta dem med Docker Compose i stället. Då behöver du inte heller Node.js lokalt.

docker compose up -d                              # Storybook, dokumentationswebben, playground och Next.js
docker compose up -d storybook                    # Eller bara en av dem
docker compose exec cli npx nx test components    # Kör kommandon i containern
docker compose down                               # Stoppa
TjänstAdress
Storybookhttp://localhost:4400
Dokumentationswebbenhttp://localhost:3000
Playgroundhttp://localhost:4200
Next.jshttp://localhost:3001

Första uppstarten tar några minuter. Följ den med docker compose logs -f.
