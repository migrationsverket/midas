Komponenter

Accordion

Utfällbar komponent som minskar informationsmängden som visas för användaren.

Badge

Indikator för notiser eller status.

Breadcrumbs

Brödsmulor som visar användaren var den är i ett navigationsträd.

Button

Knapp som utför en handling, t.ex. sparar information eller öppnar ett formulär.

Calendar

Fristående kalender för att välja ett datum eller ett datumintervall.

Card

Ett kort används för att presentera innehåll på ett strukturerat sätt.

Checkbox

Används för att låta användaren välja inget, ett eller flera alternativ.

ColorSchemeSwitch

Växlare för färgschema (ljust, mörkt, systemets inställning).

ComboBox

Fält där användaren kan söka och välja bland alternativ i en lång lista.

DatePicker

Fält för att välja ett datum eller ett datumintervall med kalender.

DateField

Använd ett datumfält när användaren ska fylla i ett datum.

EmptyState

Meddelande som visas när det inte finns något innehåll att visa.

Filuppladdning

Filuppladdning med FilePicker, FileTrigger, DropZone och FileList.

Grid

Rutnät för att placera innehåll i responsiva kolumner.

Heading

Rubrik i olika nivåer (h1 till h6) med designsystemets typografi.

InfoBanner

Banner som visar viktiga och aktuella meddelanden om händelser eller förändringar.

Layout

Modulärt layoutpaket för att sätta ihop sidstruktur med komponenter.

LinkButton

Länk som ser ut som en knapp.

Link

Länk som kan ligga i ett textstycke eller stå fristående.

Logo

Migrationsverkets logotyp.

Menu

Meny som samlar ihop funktioner.

Modal

Dialogruta som visas ovanpå sidan och fångar användarens uppmärksamhet.

Pagination

Paginering för tabeller.

Popover

Ruta som visar extra information, inställningar eller val utan att lämna sidan.

ProgressBar

Visar hur långt en process har kommit.

Radio

Radioknappar som tvingar fram ett enda val bland flera alternativ.

SearchField

Inmatningsfält anpassat för sökning.

Select

Hopfällbar lista som låter användaren välja ett eller flera alternativ.

Skeleton

Platshållare som visas i stället för innehållet tills det har laddats.

Spinner

Upplys användaren om att systemet laddar.

Stack

Ordnar element i en riktning med avstånd mellan dem.

Table

Tabell för att visa data, med stöd för sortering och val av rader.

Tabs

Organisera information med hjälp av flikar.

Tag

Etikett som visar status eller kategoriserar information.

Text

Brödtext med designsystemets typografi.

TextArea

Inmatningsfält för längre texter över flera rader, ibland med en teckengräns.

TextField

Inmatningsfält för kort och specifik information i ren text.

TimeField

Använd ett tidsfält när användaren ska fylla i en tid.

Toast

Tillfälligt, kort meddelande om åtgärder, fel eller andra händelser.

Tooltip

Liten textruta som visas när användaren hovrar över eller fokuserar ett element.
