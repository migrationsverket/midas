Komponenter

📄️Accordion

Dragspelskomponenten låter användare visa och dölja delar av relaterat innehåll på en sida.

📄️Badge

Badge används tillsammans med en ikon eller knapp för att påvisa att användaren har något oläst att ta del av.

📄️Breadcrumbs

Brödsmulor används för att visa användaren var hen är i ett navigationsträd.

📄️Button

Knappar används när användaren vill utföra en handling t.ex. spara ifylld information eller öppna ett formulär.

📄️Calendar

Använd en kalender när användaren ska välja ett datum eller visualisera ett datum valt på annat sätt.

📄️Card

Ett card är en modulär komponent som används för att presentera innehåll på ett strukturerat och visuellt tilltalande sätt.

📄️Checkbox

Används för att låta användaren välja inget, ett eller flera alternativ.

📄️ColorSchemeSwitch

Växlare för färgschema (ljust, mörkt, systemets inställning)

📄️ComboBox

Sökbar version av Select

📄️DatePicker

Fält för att välja ett datum eller ett spann av datum med kalender.

📄️DateField

Använd ett datumfält när användaren ska fylla i ett datum.

📄️DropZone

Ett generellt mål för drag & drop — inte begränsat till filuppladdning.

📄️FileList

Lista uppladdade filer

📄️FileTrigger

Åtkomst till filsystemet

📄️Grid

Grid baserat på tekniken display flex i css
