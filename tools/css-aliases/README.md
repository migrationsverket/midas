# css-aliases

This library was generated with [Nx](https://nx.dev).

Explicit `resolve.alias` entries for the `@midas-ds/*` package CSS exports (e.g.
`@midas-ds/components/default.css`) that native Vite `resolve.tsconfigPaths`
can't resolve through the tsconfig wildcard alone.

## Building

Run `nx build css-aliases` to build the library.
