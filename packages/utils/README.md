# @midas-ds/utils

Shared internal utilities for the Midas design system. Exists so small, independently-installable packages (like `@midas-ds/logo`) can reuse the same helpers as `@midas-ds/components` without depending on the whole component library.

## Installation

```bash
npm install @midas-ds/utils
```

## Usage

```tsx
import { clsx, useLocalizedStringFormatter } from '@midas-ds/utils'
```
