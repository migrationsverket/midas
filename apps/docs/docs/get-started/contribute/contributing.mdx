# 🔨 Bidra med kod

Den här sidan gäller alla kodändringar, från en buggfix till en ny komponent.

## Innan du börjar

Är ändringen större än en buggfix, skapa gärna ett [issue](/get-started/support) först så att vi kan prata ihop oss. Utgå från hur befintliga komponenter är byggda och läs om vår [arkitektur](/get-started/contribute/architecture).

## Det här ska finnas med

- **Stories** för alla tillstånd som ändras eller tillkommer, i Storybook.
- **Tester** som täcker ändringen, ofta med en story som utgångspunkt. Se [Tester](/get-started/contribute/tests).
- **JSDoc på engelska** för nya props. API-tabellerna i dokumentationen genereras från dem.
- **En dokumentationssida** med exempel, om det är en ny komponent eller ett nytt beteende som användare behöver känna till.

## Innan du skapar en PR

- [ ] `npx nx test <projekt>`, `npx nx lint <projekt>` och `npx nx stylelint <projekt>` går igenom
- [ ] Commits följer våra [commit-konventioner](/get-started/contribute/conventions)
- [ ] Commit-historiken är städad (`git rebase -i` vid behov)

Ändrar du hur något ser ut visar CI skillnaderna i de [visuella testerna](/get-started/contribute/tests#-visuella-tester). Är ändringen avsiktlig lägger du till etiketten `visual:update` på PR:en.

När PR:en mergas släpps ändringen automatiskt.
