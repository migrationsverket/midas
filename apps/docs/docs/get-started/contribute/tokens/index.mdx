# 🎨 Design Tokens

Design tokens är de minsta beståndsdelarna i designsystemet och utgör grunden för all styling. De representerar
designbeslut som färger, typsnitt, avstånd och andra visuella egenskaper.

## DTCG-standard

Våra design tokens följer [Design Tokens Community Group (DTCG)](https://design-tokens.github.io/community-group/format/) standarden. Detta innebär att våra tokens
är strukturerade på ett sätt som är kompatibelt med andra verktyg och plattformar som också följer denna standard.
Det gör det enklare att dela och återanvända våra designbeslut över olika projekt och teknologier.

```json title="tokens.json"
{
  "color": {
    "$type": "color",
    "black": {
      "base": {
        "$value": "#000",
        "$description": "Black"
      },
      "hover": {
        "$value": "#0d0d0d",
        "$description": "Black hover"
      }
    }
  }
}
```

## Arbeta med tokens

Alla tokens ligger i `packages/theme/tokens/`. [Style Dictionary](https://styledictionary.com/) gör om dem till CSS-variabler och ett JS-objekt i paketet `@midas-ds/theme`. Det sker automatiskt när du bygger, startar eller testar ett paket som använder dem, så du behöver aldrig generera något själv.

Tokens finns i tre nivåer:

- **Primitiver** (`color.*`, `base.*`) är de råa värdena, till exempel en färgskala.
- **Semantiska tokens** (`background.*`, `text.*`, `button.*` osv.) beskriver en roll i gränssnittet och refererar till primitiver.
- **CSS-variabler** (`--midas-*`) genereras från de semantiska tokens, och det är de som komponenterna använder.

Några regler:

- Semantiska tokens refererar direkt till primitiver, inte till andra semantiska tokens. Då påverkar en ändrad token bara det den själv används till.
- Använd `--midas-space-*` och `--midas-size-*` i komponenternas CSS, aldrig `--midas-base-*`.
- Ta inte bort eller byt namn på en token direkt. Lägg det gamla namnet i `deprecated.json` som en referens till det nya, med `@deprecated` i beskrivningen, så att det finns kvar till nästa major-version.

En komplett lista över alla tokens finns på sidan [Tokens list reference](dev-tokens).
