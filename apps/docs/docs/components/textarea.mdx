Inmatningsfält som används när användaren behöver fylla i längre information t.ex. en beskrivning, kommentar eller fritext. För kortare, striktare inmatning används [TextField](/components/textfield).

```tsx
import { TextArea } from '@midas-ds/components'
```

```tsx
<TextArea
  label='Kommentar'
  description='Skriv en kommentar'
/>
```

<div className='card'>
  <TextArea
    label='Kommentar'
    description='Skriv en kommentar'
  />
</div>

## Beskrivning

TextArea är en komposition av `<TextField>`, `<TextArea>`, `<Label>`, `<FieldError>` och `<Text>` som alla är React Aria-komponenter.

Med undantag för `type`-attributet erbjuder `TextArea` samma API som `TextField`, vänligen använd [dokumentationen för TextField](../textfield) för mer information.

## Context

Med `TextFieldContext` kan du ange standardvärden för alla `TextArea` inuti, egenskaper som anges direkt på komponenten har företräde. Läs mer under [Contexts](/dev/contexts).

```tsx
<TextFieldContext.Provider value={{ size: 'medium' }}>
  <TextArea label='Meddelande' />
</TextFieldContext.Provider>
```
