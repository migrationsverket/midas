## Användning

Kalender kan användas när användaren ska välja ett datum eller visualisera ett valt datum. Normalt sett
är [DatePicker](/components/date-picker) standardvalet för att välja ett datum men kalendern kan användas när inputfältet inte
behövs, när inputfältet inte ligger i direkt anslutning till kalendern eller om kalendern inte ska presenteras som en popover.

## Varianter

### Calendar

Kalendern accepterar samma props som [DatePicker](../date-picker) och controlled value sätts med `value` respektive `onChange`,
uncontrolled value sätts med `defaultValue`.

### RangeCalendar

Samma props som [DateRangePicker](../date-picker#daterangepicker), exempel nedan med controlled value:

```tsx
import { RangeCalendar } from '@midas-ds/components'
import { DateValue } from 'react-aria-components'

export const RangeCalendarExample = () => {
  const [selected, setSelected] = React.useState<{
    start: DateValue
    end: DateValue
  } | null>(null)

  return (
    <>
      <RangeCalendar
        aria-label='Kalender'
        value={selected}
        onChange={setSelected}
      />
      <pre>
        Valda datum:{' '}
        {selected &&
          `${selected?.start.toString()}
           till: ${selected?.end.toString()}`}
      </pre>
    </>
  )
}
```

<div
  className='card'
  style={{ display: 'block' }}
>
  <RangeCalendarExample aria-label='Kalender' />
</div>

### Månads- och årsväljare

Sätt `showMonthYearPicker` för att ge användaren möjligthet att välja en specifik månad/år utan att behöva stega igenom månaderna en i taget. Detta är användbart om användaren ofta behöver välja ett datum långt bak/fram i tiden, t.ex. ett födelsedatum.
Fungerar likadant på både `Calendar` och `RangeCalendar` (och därmed även `DatePicker`/`DateRangePicker`, som återanvänder dem).

```tsx
<Calendar
  aria-label='Kalender'
  showMonthYearPicker
/>
```

<div
  className='card'
  style={{ display: 'block' }}
>
  <Calendar
    aria-label='Kalender'
    showMonthYearPicker
  />
</div>
