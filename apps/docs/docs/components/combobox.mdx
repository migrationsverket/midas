En ComboBox är en sökbar version av Select. Combobox är lämplig att använda när listan med möjliga val är lång eftersom det ger användaren möjlighet att söka efter ett specifikt värde.

```tsx
import { ComboBox, ListBoxItem } from '@midas-ds/components'
```

## Kontrollerat val

Använd `value` och `onChange` för att styra det valda värdet i ComboBox.

```tsx
import React from 'react'
import { Key } from '@midas-ds/components'

const [selectedFruit, setSelectedFruit] = React.useState<Key | null>(null)

return (
  <ComboBox
    label='Välj din favoritfrukt eller grönsak'
    description='Du kan bara välja en'
    value={selectedFruit}
    onChange={setSelectedFruit}
  >
    <ListBoxItem id='Lime'>Lime</ListBoxItem>
    <ListBoxItem id='Äpple'>Äpple</ListBoxItem>
    <ListBoxItem id='Banan'>Banan</ListBoxItem>
    <ListBoxItem id='Kiwi'>Kiwi</ListBoxItem>
    <ListBoxItem id='Apelsin'>Apelsin</ListBoxItem>
  </ComboBox>
)
```

## Flerval

Sätt `selectionMode='multiple'` för att låta användaren välja flera alternativ. Valen visas som etiketter i fältet, och textfältet följer efter den sista etiketten. När användaren väljer något töms textfältet och listan står kvar öppen, så att det går att fortsätta välja. Platshållartexten visas bara så länge inget är valt.

```tsx
const fruits = [
  { id: 'lime', name: 'Lime' },
  { id: 'apple', name: 'Äpple' },
  { id: 'banana', name: 'Banan' },
  { id: 'kiwi', name: 'Kiwi' },
  // ...
]

return (
  <ComboBox
    label='Välj dina favoritfrukter'
    description='Du kan välja flera'
    placeholder='Välj eller sök frukt'
    // highlight-next-line
    selectionMode='multiple'
    defaultValue={['banana', 'kiwi']}
    items={fruits}
  >
    {item => <ListBoxItem>{item.name}</ListBoxItem>}
  </ComboBox>
)
```

:::

### Kontrollerat flerval

Vid flerval är `value` och `defaultValue` en lista med nycklar (`Key[]`), och `onChange` anropas med hela listan av valda nycklar.

```tsx
import React from 'react'
import { Key } from '@midas-ds/components'

const [selectedFruits, setSelectedFruits] = React.useState<Key[]>(['banana'])

return (
  <ComboBox
    label='Välj dina favoritfrukter'
    description='Du kan välja flera'
    placeholder='Välj eller sök frukt'
    selectionMode='multiple'
    value={selectedFruits}
    onChange={setSelectedFruits}
    items={fruits}
  >
    {item => <ListBoxItem>{item.name}</ListBoxItem>}
  </ComboBox>
)
```

### Ta bort val

Användaren kan ta bort ett val på flera sätt:

- Klicka på krysset i etiketten.
- Välj alternativet i listan igen.
- Tryck `Backspace` i ett tomt textfält, vilket tar bort det senast valda.
- Tryck `Shift+Tab` från textfältet för att komma till krysset i den sista etiketten, och tryck `Enter`. Ett `Shift+Tab` till går till själva etiketten, där `←` och `→` flyttar mellan etiketterna och `Delete` eller `Backspace` tar bort den som har fokus.

### Tangentbord

| Tangent | Åtgärd |
|---------|--------|
| `↓` / `↑` i textfältet | Öppna listan och flytta mellan alternativen |
| `Enter` i listan | Välj alternativet, eller ta bort valet om det redan är valt |
| `Escape` | Stäng listan |
| `Backspace` i ett tomt textfält | Ta bort det senast valda |
| `Shift+Tab` från textfältet | Gå till krysset i den etikett som senast hade fokus (först den sista), och en gång till till själva etiketten |
| `←` / `→` bland etiketterna | Flytta mellan etiketterna |
| `Delete` / `Backspace` på en etikett | Ta bort etiketten |

När en etikett tas bort med tangentbordet flyttas fokus till nästa etikett. När den sista etiketten tas bort flyttas fokus till textfältet, så att fokus inte går förlorat.

Medan listan är öppen döljs etiketterna för skärmläsare, eftersom React Aria döljer allt utanför en öppen ComboBox-lista. De blir nåbara igen när listan stängs.

## Sektioner

Vid många val kan alternativen struktureras i sektioner genom att dela in dem enligt följande:

```tsx
import { Collection, ListBoxHeader, ListBoxItem, ListBoxSection } from '@midas-ds/components'

const options = [
  {
    name: 'Grönsaker',
    children: [
      { name: 'Morot', id: 2 },
      { name: 'Broccoli', id: 3 },
      { name: 'Spenat', id: 4 },
      { name: 'Potatis', id: 5 },
      { name: 'Tomat', id: 6 },
    ],
  },
  {
    name: 'Frukter',
    children: [
      { name: 'Äpple', id: 11 },
      { name: 'Banan', id: 12 },
      { name: 'Kiwi', id: 13 },
      { name: 'Fläder', id: 14 },
      { name: 'Nektarin', id: 15 },
    ],
  },
]

return (
  <ComboBox
    label='Välj din favoritfrukt eller grönsak'
    description='Du kan bara välja en'
    items={options}
  >
    {section => (
      <ListBoxSection id={section.name}>
        <ListBoxHeader>{section.name}</ListBoxHeader>
        <Collection items={section.children}>
          {item => {
            return <ListBoxItem id={item.id}>{item.name}</ListBoxItem>
          }}
        </Collection>
      </ListBoxSection>
    )}
  </ComboBox>
)
```

:::info
`ListBox` renderas alltid via React Arias `Virtualizer`, vilket kräver en riktig webbläsares layoutmotor. I miljöer utan detta (t.ex. `happy-dom` eller `jsdom`, vanligt vid testning) kan sektionerade listor sluta rendera alternativ efter den första sektionens rubrik. Sätt `listBoxProps={{ virtualized: false }}` för att stänga av virtualisering, av testskäl eller andra anledningar.
:::

## Asynkron laddning

Om data finns på en server kan en laddningsindikator visas med en `ListBoxLoadMoreItem`-komponent.

Använd `allowsEmptyCollection` hos `ComboBox` och rendera bara `ListBoxLoadMoreItem` vid laddning för att visa ett "inga-träffar"-meddelande om sökfrågan inte gav något resultat.

```tsx
import { useAsyncList } from 'react-stately'
import { Collection, ComboBox, ListBoxItem, ListBoxLoadMoreItem, ListBoxEmptyState } from '@midas-ds/components'

const list = useAsyncList<{ name: string }>({
  async load({ signal, cursor, filterText }) {
    if (cursor) {
      cursor = cursor.replace(/^http:\/\//i, 'https://')
    }

    const res = await fetch(cursor || `https://swapi.py4e.com/api/people/?search=${filterText}`, { signal })

    const { results, next } = await res.json()

    return {
      items: results,
      cursor: next,
    }
  },
})

return (
  <ComboBox
    label='Star Wars Character Lookup'
    placeholder='Välj eller sök karaktär'
    description='Anropar ett externt API'
    inputValue={list.filterText}
    onInputChange={list.setFilterText}
    // highlight-next-line
    allowsEmptyCollection
    listBoxProps={{
      renderEmptyState: () =>
        list.isLoading ? null : (
          <ListBoxEmptyState>Inga träffar</ListBoxEmptyState>
        )
    }}
  >
    // highlight-start
    <Collection items={list.items}>
      {item => {
        return <ListBoxItem id={item.name}>{item.name}</ListBoxItem>
      }}
    </Collection>
    {list.isLoading && <ListBoxLoadMoreItem isLoading={list.isLoading} />}
    // highlight-end
  </ComboBox>
)
```

Fler exempel med bland annat infinite scroll finns i [React Arias dokumentation för ComboBox](https://react-spectrum.adobe.com/react-aria/ComboBox.html#asynchronous-loading)

## Skapa alternativ

Använd `onAction` på `<ListBoxItem>` för att utföra valfria handlingar när användaren klickar eller trycker enter. Detta exempel visar hur användaren kan skapa ett nytt alternativ för angivet `inputValue`.

```tsx
const ItemActionExample = () => {
  const [items, setItems] = useState([
    'Lime',
    'Äpple',
    'Banan',
    'Kiwi',
    'Apelsin',
  ])
  const [inputValue, setInputValue] = useState('')
  const selectedItem = items.includes(inputValue) ? inputValue : null

  const selectItem = (key: Key | null) => {
    if (key !== null) setInputValue(String(key))
  }

  const createItem = () => setItems(prev => [...prev, inputValue])

  return (
    <ComboBox
      label='Välj din favoritfrukt eller grönsak'
      description='Skapa en ny om den ej finns i listan'
      allowsEmptyCollection
      inputValue={inputValue}
      onInputChange={setInputValue}
      value={selectedItem}
      onChange={selectItem}
    >
      {inputValue.length > 0 && selectedItem === null && (
        <ListBoxItem onAction={createItem}>
          {`Skapa "${inputValue}"`}
        </ListBoxItem>
      )}
      {items.map(item => (
        <ListBoxItem
          key={item}
          id={item}
        >
          {item}
        </ListBoxItem>
      ))}
    </ComboBox>
  )
}
```
