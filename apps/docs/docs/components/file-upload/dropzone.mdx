En yta som ett eller flera objekt kan dras och släppas på. Kombinera med [FileTrigger](/components/file-upload/file-trigger) för
[filuppladdning](/components/file-upload#med-drag--drop), eller använd den fristående för andra typer av drag & drop.

```tsx
<DropZone onDrop={handleDrop}>
  <Text slot='label'>Släpp filer här</Text>
</DropZone>
```

<div className='card'>
  <DropZone style={{ width: '100%', maxWidth: 480 }}>
    <Text slot='label'>Släpp filer här</Text>
  </DropZone>
</div>

## Varianter

### Etikett

Textetiketten inuti ytan beskriver vad som ska släppas eller väljas. Används DropZone som ett fält bland andra i ett
formulär, komplettera med en etikett ovanför.

```tsx
<Label id='upload-label'>Ladda upp filer</Label>
<DropZone
  aria-labelledby='upload-label'
>
  <Text slot='label'>Släpp filer här</Text>
</DropZone>
```

<div className='card'>
  <div style={{ display: 'flex', flexDirection: 'column', width: '100%', maxWidth: 480 }}>
    <Label id='upload-label-docs'>Ladda upp filer</Label>
    <DropZone aria-labelledby='upload-label-docs'>
      <Text slot='label'>Släpp filer här</Text>
    </DropZone>
  </div>
</div>

### Validering

DropZone kan markeras som ogiltig med `isInvalid`, tillsammans med ett felmeddelande.

```tsx
<DropZone
  isInvalid
>
  <Text slot='label'>Släpp filer här</Text>
</DropZone>
<FieldError isInvalid>Filen är för stor</FieldError>
```

<div className='card'>
  <div style={{ display: 'flex', flexDirection: 'column', width: '100%', maxWidth: 480 }}>
    <DropZone isInvalid>
      <Text slot='label'>Släpp filer här</Text>
    </DropZone>
    <FieldError isInvalid>Filen är för stor</FieldError>
  </div>
</div>

Samma tillstånd kan användas för att begränsa vilka filtyper som är tillåtna:

<div className='card'>
  <ValidatedDropZoneExample />
</div>

:::tip[Typad drop-data]
`onDrop` ger en typad `DropEvent` där varje objekt i `items` är en `FileDropItem`, `DirectoryDropItem` eller
`TextDropItem`. Använd type guarden `isFileDropItem` från `react-aria` för att filtrera ut filer, se
[Filuppladdning: Med drag & drop](/components/file-upload#med-drag--drop) för ett komplett exempel.
:::

### Inaktiverad

```tsx
<DropZone isDisabled>
  <Text slot='label'>Släpp filer här</Text>
  <FileTrigger>
    <Button
      variant='secondary'
      isDisabled
    >
      <Upload
        aria-hidden
        size={20}
      />
      Välj filer
    </Button>
  </FileTrigger>
</DropZone>
```

<div className='card'>
  <DropZone
    isDisabled
    style={{ width: '100%', maxWidth: 480 }}
  >
    <Text slot='label'>Släpp filer här</Text>
    <FileTrigger>
      {/*
        Demo-only: `secondary` is transparent/outline even when enabled, but its
        disabled state currently reuses the shared washed-fill background meant
        for solid-filled variants (primary/danger). Real fix belongs in
        Button.module.css, tracked separately — this override just keeps the
        docs demo honest to Figma in the meantime.
      */}
      <Button
        variant='secondary'
        isDisabled
        style={{ backgroundColor: 'transparent' }}
      >
        <Upload
          aria-hidden
          size={20}
        />
        Välj filer
      </Button>
    </FileTrigger>
  </DropZone>
</div>

## Tillgänglighet

Ange `aria-label` på `DropZone` när ytan saknar synlig etikett, alltså ingen `<Text slot='label'>` och ingen
`aria-labelledby`. `aria-label` ersätter inte den synliga etiketten utan kompletterar den.
