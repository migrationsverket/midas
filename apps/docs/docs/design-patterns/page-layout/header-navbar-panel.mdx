# Applikationer som ska upplevas som mobilappar

Detta mönster är till för applikationer som ska upplevas som mobilappar t.ex. Min Sida och inte tänkt för interna desktopapplikationer. Det finns två varianter av detta mönster:

- Endast [Navbar](/dev/layout/components/navbar)
- [Sidebar](/dev/layout/components/sidebar) på stora skärmar och [Navbar](/dev/layout/components/navbar) på små skärmar.

Gemensamt för båda varianter är det endast finns plats för ett begränsat antal (max 5) menyalternativ eftersom det inte får plats fler i Navbar på en liten skärm.

## Sidebar och Navbar

Sidebar och Navbar ska inte användas samtidigt eftersom det blir dubbla navigeringar, så i denna variant används Navbar på små skärmar och Sidebar på stora skärmar. Sidebar är automatiskt dold på skärmar som är mindre än 640px, medan Navbar behöver döljas på skärmar större än 640px. Använd `useMediaQuery` för att göra det.

  Header,
  HeaderAction,
  HeaderActions,
  HeaderLogo,
  HeaderTitle,

  Navigation,

<Navigation>
  <NavigationItem>
    <NavigationLink

export const MobileAppSidebarNavbarExample = () => {
  const [isOpen, setIsOpen] = useState(false)
  const showNavbar = useMediaQuery('(max-width: 640px)')
  return (
    <Layout>
      <Header>
        <HeaderLogo />
        <HeaderTitle>Mitt system</HeaderTitle>
        <HeaderActions>
          <HeaderAction icon={<Bell />}>Notifieringar</HeaderAction>
          {/* Fler actions */}
        </HeaderActions>
      </Header>

      <LayoutContent>
        <Sidebar title='Navigation'>
          <NavigationContent />
        </Sidebar>
        <Main>
          <Button onPress={() => setIsOpen(true)}>Öppna panel</Button>
        </Main>
        <Panel
          id='detaljer'
          title='Detaljer'
          isOpen={isOpen}
          onOpenChange={setIsOpen}
        >
          {/* Panelinnehåll */}
        </Panel>
      </LayoutContent>
      {showNavbar && (
        <Navbar>
          <NavigationContent />
        </Navbar>
      )}
    </Layout>

)
}
