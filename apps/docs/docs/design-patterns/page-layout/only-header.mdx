# Header

För applikationer som inte har någon navigation, tex ensidiga formulär, så används endast vår [Header](/dev/layout/components/header). Headern kan innehålla globala handlingar som t.ex. notiser och logga ut.

```tsx
<Header>
  <HeaderActions>
    <HeaderAction icon={<LogOut />}>Logga ut</HeaderAction>
  </HeaderActions>
</Header>
```
